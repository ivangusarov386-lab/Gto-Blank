# ГТО · Печать удостоверений — version2

Статический сайт для подготовки удостоверений на готовых бланках 140 × 95 мм. Импорт, проверка, настройка принтера и печать выполняются в браузере. Эта версия разрабатывается в ветке `version3`; `main` остаётся исходной версией. Для публикации второй версии настройте нужную ветку отдельно.

## Запуск

```sh
python3 -m http.server 8950 --bind 127.0.0.1
```

Главная: `http://127.0.0.1:8950`. Прямой вход в редактор: `http://127.0.0.1:8950/?editor=1#studio`. Node.js не нужен для просмотра готовой версии: необходимые сборки включены в Git.

## Работа с участниками

1. Загрузите CSV, XLSX или XLS до 10 МБ. CSV распознаёт UTF-8 и Windows-1251; кодировку можно выбрать вручную. В Excel можно выбрать лист. Ограничение — 10 000 строк данных и 200 столбцов.
2. Проверьте первые строки и сопоставление колонок. Неполные записи остаются в списке для исправления, пустые/несопоставленные строки учитываются в отчёте. До подтверждения текущий список не меняется.
3. Заполните обязательные поля: номер, фамилию, имя, ступень, дату и номер приказа, дату выдачи. Отчество необязательно. Даты — ДД.ММ.ГГГГ, ступени — I–XVIII или 1–18. Проверяются календарные даты, повторяющиеся номера и выход текста за лист.
4. Скачайте **заполненный CSV**, чтобы сохранить правки. CSV-шаблон — отдельная кнопка с пустыми заголовками. Формульные префиксы экранируются апострофом для открытия в табличных редакторах.
5. Печать выбранной записи блокируется при ошибках. Перед тиражом показываются готовые записи и проблемы; печать только готовых требует отдельного явного подтверждения.

Список по умолчанию хранится только в памяти. При уходе с изменениями без экспорта браузер может показать стандартное предупреждение. Оно не гарантировано при принудительном закрытии приложения/вкладки.

**Локальный черновик** включается отдельным флажком. Он сохраняет персональные данные в localStorage этого браузера и восстанавливается в течение 24 часов после последней правки. При истечении срока открытая вкладка удаляет черновик; если браузер закрыт, просроченная запись удаляется при следующем открытии сайта. Кнопка удаления очищает список, историю правок и локальный черновик. Это хранение на устройстве, а не защищённое облачное хранилище.

## Калибровка

Перетаскивайте поля мышью/пальцем. Выделенное поле можно двигать стрелками на 0,2 мм, с Shift — на 1 мм. Esc отменяет перетаскивание. На телефоне удобнее выбрать поле из списка, увеличить макет и использовать крупные кнопки сдвига; шаг выбирается отдельно.

«Уместить текст» уменьшает шрифт только выбранного поля, не меняя масштаб всего листа. Размер ниже 6 пт автоматически не назначается; в таком случае нужна ручная правка. Числовые координаты доступны в раскрывающейся точной настройке.

Текущая калибровка сохраняется локально. **Профиль принтера** — отдельная сохранённая копия: введите новое название и нажмите «Сохранить профиль», чтобы создать другой профиль. Переключение, удаление, резервная копия JSON и импорт профилей доступны в настройках. При импорте существующие профили не заменяются. Сброс требует подтверждения; изменения калибровки можно отменять и повторять в текущей вкладке. Старые координаты и смещения мигрируют без автоматического сдвига.

Рамка предпросмотра не участвует в координатах. В печать попадают только данные участников; фоновый текст, линии и подсветка не печатаются. Изображение бланка — схема, а не точный скан. Сделайте пробную печать на вашем принтере: **100% / фактический размер**, без колонтитулов, бумага **140 × 95 мм**. Физическая точность зависит от драйвера, подачи и оригинального бланка.

## Разработка

Node.js 22+:

```sh
npm ci
npm run check
npm test
npm run build
```

После любых изменений CSS, JS или SVG запускайте `npm run build` и сохраняйте обновлённые ссылки в `index.html`, `assets/experience.js` и сборки. Контентные версии предотвращают загрузку старого CSS с новой разметкой.

- `assets/app.js` — исходный редактор и печатные координаты.
- `assets/data.js` — правила импорта, CSV-экспорта и валидации без DOM.
- `assets/workspace.js` — предосмотр импорта, черновик, профили, проверка печати и мобильные инструменты.
- `assets/workspace.css` — геометрия, доступность и рабочие элементы.
- `src/site-v2.css` → `assets/site-v2.css` — общий CSS с явными слоями `legacy`/`v2`, включая прежние проверенные стили. Сайт загружает одну скомпилированную таблицу стилей; runtime `@import` нет.
- Golos Text — локальные кириллический и латинский WOFF2 из `@fontsource-variable/golos-text@5.3.0`. Сборка создаёт контентные имена файлов, предзагружается только кириллица. Лицензия: `docs/GOLOS-LICENSE.txt`.
- `src/hero-3d.js` → `assets/hero-3d.js` — необязательная Three.js-сцена; статичный резерв на телефонах, при снижении анимации и ошибках WebGL.
- `src/excel.js` → `assets/excel.js` — локальный ленивый модуль Excel, без CDN. Использован npm-пакет `@e965/xlsx@0.20.3`, перепубликация SheetJS CE с проверкой integrity из lockfile. Лицензии: `docs/SHEETJS-LICENSE.txt`, `docs/THREE-LICENSE.txt`.

## Проверки

При работающем локальном сервере и установленном Chromium:

```sh
python3 -m pip install playwright
python3 tests/template.py
python3 tests/smoke.py
python3 tests/drag.py
python3 tests/experience.py
python3 tests/operations.py
python3 tests/accessibility.py
python3 tests/version2.py
```

Если Chromium установлен по другому пути, задайте `CHROMIUM_PATH`. `npm ci` нужен для Excel-фикстур и axe-core. `npm test` запускает независимые проверки календарных дат, обязательных полей, дубликатов, CSV и номеров исходных строк.

`operations.py` проверяет исправления аудита, включая DOM-геометрию печати, импорт настоящих XLSX/XLS без внешней сети, профили, экспорт, черновики и мобильные инструменты. `accessibility.py` проверяет пять отрисованных состояний axe-core и сохраняет результаты в `/tmp/gto-ecc-validation`. Автоматическая проверка не является полным подтверждением WCAG; Safari/iOS и физический принтер в этой среде не проверялись.

## Version3: спортивный hi-tech

Текущий дизайн «ГТО / Арена»: [концепция и токены](design-system/gto-arena/MASTER.md), исходник `src/arena.css`. Шрифты Golos и Oswald локальные; сборка обновляет хеши CSS, SVG и предзагрузок. Изменения интерфейса ограничены экраном; печатный шаблон остаётся 140 × 95 мм.

Три типа бланка: золотой, серебряный и бронзовый. Тип выбирается для всего тиража; профили принтеров и координаты изолированы по типу. Дополнительные поля серебра/бронзы: орган исполнительной власти, должность и ФИО подписанта; их можно импортировать и экспортировать в CSV. Исходные золотые координаты сохраняются без масштабирования. Серебро/бронза — стартовая схема по фотографиям, требующая пробной печати.
