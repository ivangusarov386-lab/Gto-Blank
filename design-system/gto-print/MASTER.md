# ГТО: Печатная студия

## Назначение и аудитория

Сервис для сотрудников центров тестирования ГТО: таблица участников → проверка → точное совмещение → печать текста на готовых бланках. Работа выполняется в `version2`.

## Решение арт-директора

Основной образ — широкая монтажная поверхность с удостоверением и метками совмещения. Центрированная типографическая композиция сменяет прежнюю схему «текст слева / иллюстрация справа». Темно-синий первый экран визуально отделяет презентацию от светлого рабочего инструмента. Золото относится к знаку отличия, синий — к действиям и настройкам.

```text
Логотип                                  Навигация / редактор
┌──────────────────────────────────────────────────────────┐
│                  Крупный заголовок                       │
│                 Объяснение / действие                    │
│ ┌──────────────────────────────────────────────────────┐ │
│ │ Формат          Удостоверение          Совмещение     │ │
│ │               Метки и рабочая сетка                   │ │
│ └──────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────┘
Импорт                   Совмещение                   Данные
Подготовка к печати / режимы / последовательность
Данные участников        Бланк на монтажной поверхности
```

На телефоне — одна колонка; боковые декоративные спецификации скрыты, текстовое объяснение пользы доступно ниже. Главное действие сохраняет заметность. В режиме редактора презентация скрывается и WebGL освобождается.

## Токены

| Роль | Значение |
| --- | --- |
| Презентационная поверхность | `#142253` |
| Основное действие | `#153dcc` |
| Светлая монтажная поверхность | `#e6ecff` |
| Фон инструмента | `#f4f5f8` |
| Основной текст | `#202632` |
| Белый текст/поверхность | `#ffffff` |

Golos, локальная кириллица: заголовок 550, сжатый трекинг, адаптивный размер через rem + vw в clamp; основной текст 1rem. Системные подписи компактнее. На сенсорных устройствах поля ввода — не меньше 1rem. Печатные Times New Roman/Georgia, размеры мм/пт и данные не менялись.

Закругления различают роли: 28px — презентационный блок; 16–18px — рабочие поверхности; капсулы — главное действие и переключатель режимов. В редакторе контрастные активные состояния сопровождаются текстом/aria-pressed; фокус, клавиатура и альтернативы перетаскиванию сохранены.

## Применение UI/UX Pro Max

Источник: nextlevelbuilder/ui-ux-pro-max-skill, `4f2dbb67e64969a9a30ab00742f2d55d66ddec2b`. Установлен локально с данными и скриптами.

1. `sports productivity precision --design-system`: найден спортивный Hero-Centric/Vibrant, но фанатская подача и Bebas Neue не подходят рабочему инструменту и кириллице; вывод не принимался как система.
2. Уточнение `document productivity tool --design-system`: найден Product Demo + Features / Flat Design. Применены демонстрация результата, ясное основное действие, минимальные эффекты и доступность.
3. Рекомендованные teal и Plus Jakarta Sans заменены по запросу пользователя (без зелёного) и необходимости полноценной кириллицы. Выше зафиксирована адаптированная система, а не необработанный вывод поиска.

Стек — HTML/CSS/JS без фреймворка. Tailwind/React и GSAP не добавлялись. Сохраняется существующая необязательная Three.js-сцена с SVG-резервом и отключением для mobile/reduced-motion. Новая анимация не нужна для понимания сервиса.

## Реализация и проверка

`src/print-studio.css` подключён в существующую сборку через явный слой `art` после `legacy, v2`. Все новые правила ограничены экраном; в HTML остаётся один собранный CSS. Название сервиса сохранено дословно.

- `tests/version2.py`: CTA, фокус, модальные окна, PDF 138 × 99 мм, 320–1440px, масштаб текста 200%, новая композиция лендинга, отсутствие ошибок ресурсов.
- `tests/accessibility.py`: пять состояний axe WCAG A/AA.
- `tests/experience.py`: WebGL, резерв SVG, reduced-motion, переходы, мобильная загрузка без Three.js.
- `tests/drag.py`, `tests/template.py`: перетаскивание и печатный шаблон.
- Проверены скриншоты настольного и мобильного интерфейсов. Физическая печать и Safari/iOS в этой среде не проверялись.

Modern Web Guidance: `responsive-design` — размеры через rem + vw в clamp и резервирование иллюстрации; `css` — явная иерархия слоёв и семантические токены. Руководства найдены запросом `responsive visual layout` и прочитаны до реализации.
