# Серебряный бланк: геометрия по «ГТО.pdf»

Образец пользователя — одностраничный растровый скан уже заполненного пробного отпечатка. Цифровая страница PDF: 1559,42 × 2274,99 pt, поворот содержимого на 90°. Это не формат для непосредственной печати 1:1. Геометрия печатных линий нормирована на подтверждённый физический разворот **140 × 95 мм**. Использованы линии оригинального бланка, а не координаты напечатанных демонстрационных ФИО. Файл пользователя в репозиторий не копируется.

В скане остаются небольшие изгибы/наклоны бумаги; измерения служат стартовой калибровкой. Цифровая проверка не заменяет отпечаток на конкретном принтере.

## Системная ошибка прежней схемы

Не существовало одного подходящего общего смещения: номер был выше строки, дата приказа и подписант ниже. У органа власти на оригинале две линии. Даты оригинала разбиты на день/месяц/две цифры года, перед которыми уже напечатано «20». Прежний вывод полной даты одной строкой не соответствовал этому бланку.

Верх текста выбран с учётом фактической базовой линии Times New Roman в генерируемом PDF. ## Даты

Ввод и CSV остаются ДД.ММ.ГГГГ. На серебре `12.03.2026` печатается как `12`, `марта`, `26` в отдельных местах. «20» остаётся только в справочной подложке и не печатается. Вся дата по-прежнему перемещается и отменяется одним полем.

Для приказа горизонтальные смещения частей относительно начала поля: 0 / 6,8 / 22,9 мм; для выдачи — 0 / 5,8 / 23,1 мм. Проверка переполнения учитывает реальные интервалы, ширину месяца и окончания года. Размер шрифта можно менять; автоматическое уменьшение не пытается сжать фиксированные промежутки. Год вне 2000–2099 блокирует печать на этом шаблоне, поскольку век уже напечатан.

## Сохранённые настройки

- Новые экземпляры серебряного шаблона получают эту схему.
- Прежние нетронутые заводские координаты автоматически мигрируют в `layoutVersion: 2`, сохраняя смещение принтера.
- Любые отличающиеся пользовательские координаты не заменяются автоматически.
- В «Калибровка принтера» доступна кнопка **«Применить схему серебра по PDF»**. Она меняет рабочие координаты и размеры полей, сохраняет смещение принтера и именованные профили; доступна отмена.
- Именованный профиль можно обновить после успешной пробной печати.
- Золото и бронза не измерялись по этому PDF и не получают серебряные координаты.

`tests/silver-layout.py` проверяет базовые линии настоящего PDF, раздельный формат дат, сохранность исходного значения в форме, ограничение века, интервалы частей даты и совместное перемещение, безопасную миграцию, отмену и неизменность именованных профилей/смещения.
