# Исправления по аудиту ECC

Реализованы пункты исходного аудита `docs/ecc-site-audit.md`. Проверка относится к текущему локальному коду; опубликованный GitHub Pages и физический принтер отдельно не проверены.

| Пункт | Реализация | Проверка |
| --- | --- | --- |
| Геометрия | Рамка стала внутренней тенью, не добавляет 1 px к началу координат; масштаб использует дробную физическую ширину | Отрисованное положение фамилии в предпросмотре и print-sheet отличается менее чем на 0,02 px при ширинах 375/1440 px |
| Готовность | Обязательные поля, настоящие даты, I–XVIII/1–18, дубликаты; ошибки связаны с полями | Неполные и невозможные даты не печатаются; отчество может отсутствовать |
| Тираж | Диалог с количеством готовых и ошибками; отдельное подтверждение печати только готовых | Из двух записей с одной ошибкой печатается ровно одна после явного подтверждения |
| Переполнение | Измерение текста с печатным шрифтом, подсветка и блокировка; уменьшение шрифта выбранного поля | Длинная фамилия блокируется; подстройка обратима и не меняет масштаб листа |

## Сохранённые границы

- Фон бланка остаётся схемой. Нужен пробный отпечаток для проверки реального драйвера и подачи.
- Геометрия исправлена без автоматического изменения сохранённых координат. Если координаты подгонялись по старой рамке, перепроверьте их на бумаге.
- Черновик содержит персональные данные только после явного разрешения. localStorage не шифруется, доступен на этом устройстве; удаление просроченных данных при закрытом браузере происходит при следующем открытии сайта.
- Экспорт означает подготовку файла к скачиванию; приложение не может подтвердить, что ОС сохранила его на диск.
- Автоматический axe не заменяет ручную проверку экранным диктором; Safari/iOS не запускались.
- Подтверждение тиража — подготовка и вызов системной печати, а не подтверждение успешного физического отпечатка.

Архитектура остаётся статической: без сервера, базы данных, внешней отправки списков и миграции на другой фреймворк. Новые зависимости нужны для локального чтения Excel и проверки доступности.
