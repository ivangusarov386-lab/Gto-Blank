# Version2: Frontend Design и Modern Web Guidance

Изменения выполнялись в ветке `version2` на базе `dd1abdb`. Ветка `main` не изменялась.

## Дизайн-план и результат

Сайт — рабочий инструмент центров тестирования ГТО. Основное действие: подготовка текста для готового бланка. Визуальная идея — спокойная документная мастерская с характерным знаком отличия, а не абстрактная SaaS-презентация.

Палитра: графит `#1c2431` (текст), глубокий синий `#244b83` (действия), серо-белый `#f7f8fb` (страница), `#edf1f7` (второстепенные поверхности), `#536173` (подписи), `#a6742f` (ограниченный золотой акцент знака ГТО). Синий также применён к обложке и ленте медали в 3D и резервной иллюстрации. Шрифт интерфейса — Golos Text с локальными кириллическим и латинским подмножествами; Times New Roman и Georgia внутри бланка сохраняются.

Схема:

```text
Шапка: знак / название          Возможности / редактор
Заголовок и действие           Удостоверение и знак ГТО
Реальные возможности сервиса
Подготовка к печати / режимы / три последовательных шага
Участники и редактирование     Фиксированный макет бланка
```

Выравнивание текста — по левому краю. В редакторе важны список, ошибки, выбранная запись и макет; хранение данных раскрывается через нативный details. Сохранён запрошенный заголовок «Сервис печати удостоверений ГТО». При переходе в редактор его собственное название становится единственным видимым h1.

Первоначально рассмотренную привычную схему с цветовым выделением половины заголовка, декоративными прописными подписями и сиянием под медалью убрали: она не объясняет работу с бланками. Выразительность сосредоточена в знаке и печатном развороте; фон, навигация и действия остаются спокойными.

## Применённые рекомендации

| Руководство | Изменение и конкретное правило |
| --- | --- |
| dialog | Сохранены нативные showModal/close; безопасные кнопки закрытия получили autofocus — “DO put autofocus on the safe action”. Нет ручного focus trap или root scroll lock. |
| prevent-page-scroll-under-modal-dialog | `dialog:modal` и `dialog::backdrop` получили overscroll-behavior; backdrop стал scroll container с overflow:hidden. Правило: “DO NOT apply overflow: hidden or position: fixed to html or body”. Корневые стили прокрутки не меняются. |
| responsive-design | Панели используют inline-size container queries для инструментов калибровки; размеры заголовков используют rem + vw в clamp; диалоги сохраняют ограничение dvh; проверен reflow при 200% тексте — “combine viewport-relative and font-relative units in clamp()”. Физический бланк остаётся в мм/пт. |
| css | Компилируемые слои legacy/v2 задают приоритет без ещё одного слоя конкурирующих подключённых стилей — “Use cascade layers”. Новые состояния hover исключают disabled. |
| html | Поиск оформлен через search, шаги — ol/li, вид и заголовок страницы соответствуют режиму — “DO use search to enclose search and filtering mechanisms”. Ссылки перехода и skip link ведут к фокусируемому заголовку. |
| accessibility | Убраны объявления счётчиков при каждом символе; объявления перемещения задерживаются на 160 мс — “Debounce frequently-changing regions”. Добавлены явные связи label/for вложенных настроек. Ошибки остаются связанными с полями. |
| performance | Четыре исходных стилевых слоя собираются в один CSS, без сетевых цепочек @import. Предзагрузка кириллицы использует crossorigin: “even same origin fonts”. Чтения геометрии предпросмотров сгруппированы до записей. При переходе в редактор WebGL освобождается и не загружается для скрытой сцены. |

`efficient-background-processing` проверен, но content-visibility не добавлялся: сцена находится на первом экране, а performance рекомендует “DON'T apply content-visibility: auto to above-the-fold content”. Сохранены IntersectionObserver и Page Visibility, которые уже останавливают анимацию вне экрана/в фоновой вкладке.

Внешние сервисы не получают списки, DOM, скриншоты или исходники. Шрифты загружаются с самого сайта.

## Проверка и ограничения

- `tests/version2.py`: локальный шрифт, один CSS, заголовки, клавиатурный skip link, автофокус безопасной кнопки, Escape и возврат фокуса, отсутствие root scroll lock, размер PDF 138 × 99 мм, адаптивность 320/375/768/1024/1440 px с 100% и 200% размером текста.
- В Chromium 156 фон при прокрутке поверх backdrop остался на том же scrollY. Это не утверждение о поведении всех браузеров.
- `tests/accessibility.py`: пять состояний, автоматические WCAG A/AA проверки axe. Полная проверка экранным диктором этим не заменяется.
- Существующие сценарии печати, координат, импортов, профилей, черновиков и перетаскивания остаются обязательными.
- Ограничение scroll chaining на нескроллируемом backdrop — progressive enhancement; старые браузеры и Safari могут разрешать фоновой странице прокручиваться. Нативная модальность, inert и клавиатурный фокус сохраняются. Корневые overflow/fixed хаки и ненужные полифилы не добавлялись.
- Размер бланка и печатный шрифт не изменены. Физическая печать, Safari/iOS и опубликованный сайт в этой проверке не запускались.
